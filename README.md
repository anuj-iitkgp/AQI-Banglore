# AQI Bangalore Prediction & Analysis 🌤️🍃

This project analyzes and predicts the Air Quality Index (AQI) for Bangalore using data science and machine learning techniques.

## 📌 Features
- **Data Collection/Preprocessing:** Cleaned and formatted historical air quality data of Bangalore.
- **Data Visualization:** Trends and graphs showing seasonal pollution patterns.
- **Machine Learning Models:** Trained algorithms to predict AQI levels based on pollutants (PM2.5, PM10, NO2, etc.).

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn
